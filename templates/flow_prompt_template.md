# Google Flow 首尾帧模式模板

复制完整代码块并替换占位符。将两张实际图片分别上传到 Start frame 和 End frame 槽位，设为 8 秒。

```text
使用首尾帧模式生成 8 秒视频。

Start image：{首帧图片文件名}
End image：{尾帧图片文件名}

要求：
- 必须从 Start image 的画面状态自然运动到 End image 的画面状态。
- 严格遵循首帧到尾帧的顺序，不得颠倒。
- 不得将 End image 作为视频起始画面。
- 不得擅自改变首尾帧所确定的画面内容。

限制：
- 无多余角色
- 无文字
- 无水印
- 无肢体畸形
- 无重影
- 无异常手部结构

画幅与风格：{比例、画风、光线}
场景与角色：{环境、身份、服装、起始位置与道具状态}
动作时间轴：0–2 秒{从首帧起步}，2–5 秒{主动作与表情变化}，5–8 秒{自然到达尾帧}
运镜：{起止景别与机位、移动方向和速度}
动作检查：{持握、脚步、道具轨迹和停止状态}
环境音：{需要的声音}
```
