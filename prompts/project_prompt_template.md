# AI 漫剧项目级提示词

```text
请按统一首尾帧流程设计 AI 漫剧项目。

项目名：{名称}
风格：{画风、色调、情绪}
比例：{16:9 / 9:16 / 其他}
故事简介：{起因、发展、结局}
角色：{名称、外貌、服装及配饰}
场景：{地点、时间、布局与光线}
道具：{外观、尺寸、用途与状态}
镜头数量：{数量}

先整理角色、场景及道具母版提示词。再逐镜设计编号、名称、目的、场景、角色、动作、表情、景别、机位和运镜。
每个镜头独立制作，固定 8 秒。每镜交付首帧和尾帧的画面说明、文件名、独立生成提示词，以及一条完整的 Google Flow 首尾帧视频提示词。
首帧命名为 SHxxx_KF01_START.png，尾帧命名为 SHxxx_KF03_END.png。中段动作以时间轴描述。
最后输出镜头总表和拼接顺序。
```
