# 首尾帧模式使用说明

统一使用首尾帧，可以事先确定动作从哪里开始、最后停在哪里，也方便逐镜复核起止画面。

- **首帧**是镜头的第一个画面。明确角色站位、姿势、视线、道具和机位。
- **尾帧**是同一镜头的最后一个画面。明确动作完成状态、角色表情和最终构图。
- **设计**时，两张图用同一套母版，检查中间动作能在 8 秒内自然完成。每镜独立生成，可共享角色美术和场景设定。
- **提示词**写明首尾顺序，再补充 0–8 秒的动作、表情、运镜及声音。[首尾帧提示词模板](../templates/flow_prompt_template.md)
- **操作**时分别把实际图片上传到 Start frame 和 End frame，核对槽位与文件名，设置画幅和时长。生成后回看第一帧、末帧及中间运动。[Google Flow 视频生成说明](https://support.google.com/flow/answer/16353334)
